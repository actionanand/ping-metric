speed Mbps vs MB/s

Mbps means megabits per second; B means byte. Eight bits equal one byte. ISPs normally advertise Mbps, while download tools often use MB/s. They describe the same throughput in different units.

MB/s = Mbps / 8 · Mbps = MB/s × 8

8 Mbps ≈ 1 MB/s; 40 ≈ 5; 80 ≈ 10; 100 ≈ 12.5; 1,000 ≈ 125. Real downloads can be lower because of Wi-Fi, overhead, congestion, server limits, devices, and other traffic.

download Download and upload

Download is data arriving at your device: websites, streaming and app or cloud downloads. Upload is data leaving it: video calls, backups, file uploads and live streaming.

M-Lab means Measurement Lab, a research project that provides open Internet measurement tools. PingMetric uses its NDT7 service for the dashboard's active download and upload test; the result describes the tested path at that moment, not a guaranteed plan speed.

NDT7 is Network Diagnostic Tool version 7. It transfers test data between your browser and an M-Lab server. This gives an end-to-end throughput estimate; PingMetric displays the result as download and upload speed.

Latency, ping, jitter and RTT

Latency is the time a response takes, shown in milliseconds. Lower latency usually makes browsing, calls, games and remote apps feel more responsive. PingMetric shows the median of browser HTTP/application probes and TCP timing when the browser exposes it.

HTTP (Hypertext Transfer Protocol) is the request-and-response format browsers use to load web resources. HTTPS is HTTP protected with encryption and server identity checks. PingMetric's latency probe uses a web request, so it measures the browser's application path rather than every part of the network stack.

RTT means Round-Trip Time: the time for data to go from your device to a server and for a response to return. MinRTT is the minimum TCP round-trip time observed during a transfer; RTTVar is TCP's estimate of how much RTT varies. They help describe path delay and stability. NDT7 may include them in the TCP result stored with a test; PingMetric's current dashboard does not display them separately, and they are not the dashboard's HTTP latency sample.

Jitter

Jitter is latency variation. 20, 21, 19, 20 ms is stable; 20, 80, 25, 110 ms is not. PingMetric uses the average absolute difference between consecutive HTTP/application samples. It matters for VoIP, video, games, streaming and remote control.

Loaded latency

Loaded latency is response time while a download or upload is using the connection. A large increase can indicate queues building in a modem, router, or network path. This is sometimes called bufferbloat: oversized queues add delay even though data is still moving. It matters for calls and games during downloads. PingMetric compares available latency measurements during the test; this is a clue, not a definitive bufferbloat diagnosis.

ICMP means Internet Control Message Protocol, a network-layer protocol used for diagnostics and error reports. Classic command-line ping usually sends ICMP Echo requests. Browsers do not let web pages send arbitrary ICMP packets, so PingMetric instead measures HTTP/application latency. The two tests can differ because they use different protocols and paths.

TCP and retransmission

TCP means Transmission Control Protocol. It delivers data in order and checks receipt, retransmitting data when needed. This reliability is important for web pages and downloads, but retransmissions and congestion can affect throughput. PingMetric uses TCP for the NDT7 transfer and reports its retransmission estimate as (bytesRetrans / bytesSent) × 100 when those fields exist. It is not exact packet loss; a higher value can reflect congestion, Wi-Fi interference, unstable paths or temporary loss. MinRTT and RTTVar, when present in TCP details, describe transfer timing rather than classic ICMP ping.

IP, routing and dual stack

IP means Internet Protocol. It gives devices addresses and carries packets between networks. PingMetric shows the public addresses its browser checks can reach; it cannot inspect every address inside your home or office network.

An IP-based location is an approximate estimate that can point to an ISP, carrier, VPN exit, corporate gateway or registered network location. It is not GPS. PingMetric labels these provider-reported city, region and country values as approximate.

IPv4 is Internet Protocol version 4 and uses 32-bit addresses such as 192.0.2.10. IPv6 is Internet Protocol version 6 and uses 128-bit addresses such as 2001:db8::1234. IPv6 provides a much larger address space. PingMetric reports whether IPv4, IPv6, or both (dual stack) are reachable from the browser.

NAT (Network Address Translation) lets a router share one public address across devices using private addresses. CGNAT (Carrier-Grade NAT) is similar sharing performed by an Internet provider, sometimes for many customers. It can affect inbound connections and makes a public IP identify a shared gateway rather than one device. PingMetric sees the public-facing address, not the private addresses behind NAT.

ASN means Autonomous System Number. It identifies a network that announces Internet routes, often an ISP or hosting provider; PingMetric shows it in network intelligence. CIDR means Classless Inter-Domain Routing. A range such as 203.0.113.0/24 describes a group of addresses and appears as a route/network detail. RIR means Regional Internet Registry, the regional organization responsible for allocating address resources; PingMetric shows the provider-reported RIR when available.

Anycast means the same IP address is announced from multiple locations, with routing directing traffic to one of them. It can improve reachability and response time; PingMetric may show it as an IP-intelligence classification. A bogon is an address range that should not normally appear on the public Internet. A reserved address is set aside for special uses, such as private networks or documentation, rather than ordinary public routing. PingMetric can show a bogon/reserved classification, but provider data can be incomplete or mistaken.

WebRTC and privacy

WebRTC means Web Real-Time Communication. It enables browser voice/video calls and direct data connections. PingMetric can run a bounded WebRTC check to show the network candidates the browser exposes; a candidate is not by itself proof of a privacy leak.

ICE (Interactive Connectivity Establishment) is how WebRTC gathers and tries possible connection routes. A host candidate describes a local interface, srflx (server-reflexive) describes an address learned through a server, and relay uses a forwarding server. Seeing srflx does not by itself indicate a VPN leak. PingMetric labels the candidate types it can observe.

STUN means Session Traversal Utilities for NAT; it helps a device learn how it appears outside its router. TURN means Traversal Using Relays around NAT; it forwards media when a direct route cannot be made. PingMetric's WebRTC test uses configured STUN servers and does not operate a TURN relay.

mDNS means Multicast DNS. Browsers may replace a local address in a WebRTC host candidate with a temporary-looking .local name to make the device's local address harder for a page to identify. PingMetric labels such candidates as mDNS rather than treating the name as a public IP.

Network intelligence and browser APIs

ISP means Internet Service Provider: the organization that sells or supplies Internet connectivity. A public IP may instead appear to belong to a VPN, corporate proxy or Zscaler gateway, cloud/datacenter exit, or mobile carrier gateway. The apparent ISP can differ from the provider of the physical access link. PingMetric shows provider-reported ownership when IP intelligence is enabled.

VPN means Virtual Private Network: traffic is sent through another network endpoint, often to protect traffic on the way to it. A proxy is an intermediary that makes requests or forwards traffic for a device. Tor (The Onion Router) routes traffic through multiple relays to make tracing its path harder. Datacenter/hosting means an address is associated with servers rather than a typical home connection. These are provider-reported IP classifications; PingMetric shows generic detected/not-detected states and can be wrong. They do not identify what software or service you personally use.

The Network Information API is an optional browser interface that may report an estimated connection type, downlink, and RTT. It matters as a rough local hint, not a measured line speed. PingMetric labels these as browser estimates and keeps them separate from NDT7 results.

Web Crypto is the browser's cryptographic API for operations such as hashing. PingMetric checks whether it is available for app functions; its presence does not mean every website connection or device setting is secure. A secure context is a browser page loaded in a protected setting, usually HTTPS (with localhost as a development exception). Some browser APIs, including Web Crypto features, require one. PingMetric reports whether its current page has a secure context.

DNS means Domain Name System; it looks up the address for a name such as a website domain. A DNS leak is when name lookups use a DNS provider or route different from the one a person expects, for example outside a VPN. Reliable detection needs controlled DNS servers and observation of the resolver receiving each lookup. A browser-only page cannot reliably see that path, so PingMetric marks DNS leak testing as unavailable rather than guessing.

Net Neutrality Check

Net neutrality is the principle that Internet traffic should not be unfairly favored or restricted based on its source, destination, or content. PingMetric offers a browser heuristic that compares repeated response timings and reachability for selected services. It can show observed differences, but it cannot identify why they occurred or prove ISP intent.

This is not the controlled application-like replay used by native research tools such as Wehe, and it is not a legal finding. CDN placement, service load, peering, routing, DNS, VPNs, proxies, corporate gateways, firewalls, browser extensions, congestion, outages and rate limits can all affect the observed path.

What should I avoid sharing?

Be cautious with screenshots containing full IPv4/IPv6, WebRTC addresses, coordinates, postal code, city plus network identity, ISP/ASN plus exact IP, or CIDR/route. Together, public routing details can make profiling easier. Speeds, latency, jitter, dual-stack status and generic browser support are generally less sensitive. Use “Hide sensitive info” before sharing; it visually hides details but is not encryption.
