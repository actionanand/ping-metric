About PingMetric

PingMetric is a personal Internet and network diagnostics tool. It has no accounts, telemetry, ads, or server database.

What the results mean

Download and upload are measured with M-Lab NDT7. Latency is application/TCP round-trip time, not raw ICMP ping. IP location is approximate; VPN, proxy, Tor, and hosting indicators are provider-reported and can be wrong.

WebRTC results are limited by browser privacy protections. A true DNS-leak test requires controlled authoritative DNS infrastructure and cannot be done by this browser-only app.

Privacy

PingMetric settings, consent, and test history stay on this device. Third-party services receive requests needed to look up public-IP data or run a measurement.

Sensitive network values can be visually hidden before sharing a screenshot. This is a display aid, not encryption.

Display and learning

Speed tests and history are measured and stored in Mbps. You may display them as MB/s using Mbps / 8. The Network Guide explains the terminology used throughout PingMetric.

IP intelligence

Full IP intelligence uses authenticated ipapi.is information when configured. Basic IP intelligence uses the provider’s anonymous response. If an authenticated request reaches its daily quota, PingMetric retries once anonymously so basic network information can continue.

Browser configuration values are client-visible. Do not add a private server key.

Attribution

Network measurements are provided by M-Lab. IP intelligence is provided by ipapi.is.
